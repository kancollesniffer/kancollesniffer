# KancolleSniffer バグ報告・開発案件管理

ここは KancolleSniffer のバグ報告と開発案件を管理するサイトです。

配布サイト: https://kancollesniffer.bitbucket.io/  
ソースリポジトリ: https://bitbucket.org/kancollesniffer/kancollesniffer

## バグ報告、改善提案の登録

課題を登録する前に FAQ と既存の課題を確認してください。  
https://kancollesniffer.bitbucket.io/#faq  
https://github.com/kancollesniffer/kancollesniffer/issues?q=is%3Aissue

新規のものであると確認できたら、まずは以下のガイドをよく読んでください。  
https://knowledge.sakura.ad.jp/26627/

ガイドの内容を把握出来たら、以下のページで課題の登録してください。  
https://github.com/kancollesniffer/kancollesniffer/issues/new/choose

登録された課題に対して質問することがありますので、状況にご注意ください。  
問題を再現できず質問に対して回答がない場合は、課題を打ち切る場合があります。
